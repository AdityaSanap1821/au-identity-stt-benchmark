Generated by `identity/score.py` and `identity/matcher.py` on 7 October 2026. One run per vendor, default vendor
settings plus the hints shown. Read the [limits](README.md#limits) before the numbers: samples are small and
the real-voice set is one speaker.

Vendors: AssemblyAI `universal-3-6-pro`, Deepgram `nova-3-general` (Sydney endpoint), Speechmatics agent STT,
Gemini `gemini-3.5-transcribe-live`, Whisper `large-v3-turbo` (local, segmented by VAD, so its latency is not comparable).

Hints: `none`; `generic` (street types, email domains, states); `record` (the caller's own details on file).
